# Contributing to Chess Analyzer

Thank you for your interest in contributing! Here's how to get started.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/chess-analyzer.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `pip install -r requirements.txt`

## Prerequisites

- Python 3.10+
- Stockfish engine installed and accessible
- (Optional) A free Lichess API token for the Opening Explorer feature

## Making Changes

- Follow existing code style and conventions
- Keep functions focused and well-commented
- Test your changes before submitting
- Ensure no sensitive files (API tokens, config files) are committed — check `.gitignore`

## Submitting a Pull Request

1. Commit your changes with a clear, descriptive message
2. Push to your fork: `git push origin feature/your-feature-name`
3. Open a Pull Request against the `main` branch
4. Describe what your PR does and why
5. Reference any related issues (e.g., `Closes #12`)

## Reporting Bugs

Please open an [issue](https://github.com/AntonyParks/chess-analyzer/issues) and include:
- Steps to reproduce
- Expected vs actual behavior
- Python version and OS
- Any relevant error output

## Feature Requests

Feel free to open an issue with the `enhancement` label. Describe the use case and why it would benefit the project.

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
